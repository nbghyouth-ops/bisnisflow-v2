# Template & workflow
16 template di `src/server/templates.ts` menentukan modul aktif, istilah, COA tambahan, pajak awal, checklist, pertanyaan onboarding, laporan. Workflow khusus (kind records) di `src/server/records-config.ts` berstatus per template: restoran (meja, tiket dapur), laundry (order+status), bengkel (kendaraan, job card), katering/distributor (jadwal kirim/surat jalan), fashion (koleksi), hotel (kamar, housekeeping), kontraktor (BOQ, subkontraktor, progres), gym (membership, kelas, kehadiran), jasa profesional (engagement, deliverable), pendidikan (kelas, pendaftaran, SPP manual), klinik (praktisi, antrian tanpa data medis), rental (armada, serah terima/inspeksi), lainnya (item kustom). Semua memakai skema inti yang sama; tidak ada data contoh.
