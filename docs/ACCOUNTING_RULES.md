# Aturan akuntansi
Double entry; NUMERIC(20,4); pembulatan sesuai mata uang (IDR 0 desimal) HALF_UP. `postJournal` memvalidasi akun aktif, debit=kredit, periode terbuka; trigger DB menolak jurnal tidak seimbang. Jurnal posted tidak dapat diubah/dihapus: koreksi = jurnal pembalik (`journal_entries.reversal_of`). Nomor dokumen atomik per workspace/jenis/bulan (`doc_sequences`). Sumber jurnal unik (`source_type`,`source_id`) mencegah posting ganda. Laporan: neraca saldo, laba rugi, neraca (dengan laba berjalan), arus kas langsung, buku besar, umur AR/AP — semua dari `journal_lines`. Pajak efektif-tanggal (`tax_rates`), snapshot pada baris penjualan. Multi-currency: satu mata uang per workspace; kurs disimpan sebagai data master tetapi **konversi belum diimplementasikan**.
