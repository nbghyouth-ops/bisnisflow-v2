# Persediaan & HPP
`stock_movements` append-only (qty bertanda, biaya). `stock_balances` (qty, nilai) dikunci `FOR UPDATE` dalam urutan deterministik. Metode per produk: rata-rata bergerak atau FIFO (lot `stock_lots`); metode terkunci setelah ada mutasi. Stok tidak boleh negatif (CHECK + validasi). Unit terakhir membersihkan sisa pembulatan. Transfer memindahkan biaya apa adanya. BOM + produksi: bahan (dengan waste %) + tenaga kerja + overhead → HPP unit batch; `cost_snapshots` menyimpan riwayat. Rekonsiliasi: nilai saldo = Σ mutasi = akun 1300 (`/api/v1/inventory-reconciliation`).
